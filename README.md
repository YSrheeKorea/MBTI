# 마음MBTI & 심리검사 센터 (Maeum MBTI & Psychological Test Hub)

모바일(Android/iOS PWA) 및 데스크톱 환경을 모두 지원하는 **종합 심리·성격·관계 분석 웹앱**입니다.  
전문 심리학적 척도를 바탕으로 현실적이고 깊이 있는 문항과 정밀한 2D/다축 시각화 분석 보고서를 제공합니다.

---

## 🌐 온라인 바로가기 & 스마트폰 앱 설치

- **온라인 웹 주소**: [https://ysrheekorea.github.io/MBTI/](https://ysrheekorea.github.io/MBTI/)

### 📱 스마트폰 홈 화면에 앱으로 설치하는 방법 (PWA)
1. 스마트폰 브라우저(Chrome 또는 삼성 인터넷)로 위 주소에 접속합니다.
2. 화면 상단의 **[스마트폰 홈 화면에 앱 설치하기]** 버튼 터치
   - 또는 브라우저 우측 상단 메뉴(`⋮`) → **[홈 화면에 추가]** / **[앱 설치]** 선택
3. 스마트폰 홈 화면에 전용 앱 아이콘이 생성되며, 실행 시 주소창 없는 **단독 전체화면 앱**으로 구동됩니다.

## 🧠 제공 검사 라인업 (총 10종+)

| 검사명 | 영문/약칭 | 주요 분석 내용 및 시각화 |
| :--- | :--- | :--- |
| **MBTI 성격유형 검사** | MBTI | 16가지 성격 유형, 4대 선호 지표(E/I, S/N, T/F, J/P) 정밀 비율 및 상세 특성 |
| **성인애착 유형 검사** | Attachment | 안정형 / 불안형 / 거부회피형 / 공포회피형 4사분면 2D 관계 지도 & 불안/회피 2축 스펙트럼 |
| **Big 5 성격 5요인 검사** | Big 5 (OCEAN) | 개방성, 성실성, 외향성, 우호성, 신경증 5개 차원 백분위 스펙트럼 |
| **에니어그램 검사** | Enneagram | 9가지 기본 성격 유형 식별, 주기능/부기능 및 날개(Wing) 역동 분석 |
| **DISC 행동유형 검사** | DISC | 주도형(D), 사교형(I), 안정형(S), 신중형(C) 업무 및 대인관계 행동 패턴 분석 |
| **자존감 척도 검사** | Self-Esteem | 로젠버그 자존감 척도 기반 긍정적 자아평가 및 자기효능감 레벨 판정 |
| **번아웃 증후군 척도 검사** | Burnout | 신체적·정신적 탈진, 냉소주의, 직무 효능감 저하 3단계 위험도 경고 및 관리 팁 |
| **스트레스 대처 전략 검사** | Stress Coping | 문제 중심 대처 vs 정서 중심 대처 vs 회피형 대처 균형 분석 및 스트레스 솔루션 |
| **사회적 소통 스타일 검사** | Social Style | 분석형, 주도형, 표출형, 우호형 소통 성향 진단 및 갈등 해결 가이드 |
| **이상형 연애 성향 분석** | Ideal Type | 연애 가치관, 외모 선호도, 성격 궁합 밸런스 분석 |

## 💻 로컬 실행 방법

### 1. 스마트폰 Wi-Fi 연동 런처
- `run_on_phone.bat`을 실행하면 PC 화면에 대형 QR 코드가 표시되며, 스마트폰으로 즉시 연결하여 구동할 수 있습니다.

### 2. PC 전용 앱 런처
- `run_app.bat` : 데스크톱 전용 애플리케이션으로 실행

---

## 🛠️ 개발 및 빌드 (`mbti_app`)

```bash
cd mbti_app
npm install
npm run dev     # 로컬 개발 서버
npm run build   # 프로덕션 빌드
```
